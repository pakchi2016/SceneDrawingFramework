# SceneDrawingFramework
情景描写を『ベクトル（五感）』×『レイヤー（深度）』で体系化し、抜け漏れや過剰表現を防ぐための試み。

# 深度定義
 * Layer 1【物理的認知】： 客観的な事実。そこに「何があるか」「何が起きたか」。
 * Layer 2【性質と解像度】： 状態や変化。それが「どんな特徴を持っているか」。
 * Layer 3【心象と意味】： 主観的な解釈。それが「どう感じられるか」「どんな記憶や感情を喚起するか」。

# 情景深度マトリクス
| ベクトル（五感） | Layer 1：物理的認知 | Layer 2：性質と解像度 | Layer 3：心象と意味 |
|---|---|---|---|
| 視覚（Visual） | 形状・存在（例：四角い、大きい、そこにある） | 色彩・光影・動き（例：鈍い銀色、明滅する、揺れる） | 印象・比喩（例：威圧的な、希望のような） |
| 聴覚（Auditory） | 音源・種類（例：足音、雨音、話し声） | 音質・距離・反響（例：硬い、くぐもった、遠ざかる） | 感情・情緒（例：寂しげな、神経を逆撫でする） |
| 触覚（Tactile） | 接触・温度（例：触れた、冷たい、熱い） | 質感・圧力（例：ザラザラした、重い、鋭い） | 身体的反応・浸透（例：芯まで冷える、鳥肌が立つ、安堵する） |
| 嗅覚（Olfactory） | 発生源（例：土、珈琲、煙） | 濃度・広がり（例：鼻をつく、微かに漂う、充満する） | 記憶・感情の喚起（例：昔を思い出す、安心する、胸が痛む） |
| 味覚（Gustatory） | 基本味（例：甘い、苦い、しょっぱい） | 複雑さ・食感（例：奥深いコク、舌にまとわりつく） | 精神的充足・不快感（例：心まで満たされる、砂を噛むような） |
