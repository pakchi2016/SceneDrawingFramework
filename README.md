# SceneDrawingFramework
情景描写を『ベクトル（五感）』×『レイヤー（深度）』で体系化し、抜け漏れや過剰表現を防ぐための試み。

# 深度定義
 * Layer 1【物理的認知】： 客観的な事実。そこに「何があるか」「何が起きたか」。
 * Layer 2【性質と解像度】： 状態や変化。それが「どんな特徴を持っているか」。
 * Layer 3【心象と意味】： 主観的な解釈。それが「どう感じられるか」「どんな記憶や感情を喚起するか」。

# 深度コスト（リソース管理）
これは読者の「認知リソースの管理」
読者が一度に想像できる情報量を想定して、実装する深度合計を数値化する。
例 **【シーンの最大コスト上限＝5】**と設定した場合。
 * パターンA（視覚特化型）：視覚(L3) ＋ 聴覚(L1) ＋ 触覚(L1) ＝ コスト5
   目の前の景色に強烈な感情を抱きつつ、雨音や風の冷たさは単なる事実として処理している状態。
 * パターンB（分散型）：視覚(L2) ＋ 聴覚(L2) ＋ 嗅覚(L1) ＝ コスト5
   景色も音もそれなりに意識しているけれど、決定的な心象（L3）には至っていない、どこか上の空な状態。

コストを割り振ることで、「どこに読者の意識を集中させるか」というカメラのフォーカス制御を論理的に行う。
「見せたいもの」を絞り込むことと、情報過多による読者の「胃もたれ」予防が目的。

# 深度アライメント（極性の付与）
同じ深度の組み合わせでも、そのベクトルが向かう方向（極性）によって意味が全く変わる。
例 【視覚(L1) ＋ 聴覚(L3)】（目の前の景色は形しか認識できず、音に感情が紐づいている状態）の場合。
 * 【ポジティブ（＋）】のアライメント
   優しい雨音や懐かしい音楽に心を奪われ、目の前の現実の景色がぼやけてしまうような**「陶酔」や「憧憬」**。
 * 【ネガティブ（－）】のアライメント
   不快な足音や耳障りな轟音が心臓を直接掴むように響き、目の前の景色がモノクロに褪せて見えるような**「呆然」や「絶望」**。

アライメントをあらかじめ決めておくことで、描写に使う言葉の引き出し管理の精度が上がり、平仄を合わせやすくなる。


# 情景深度マトリクス
| ベクトル（五感） | Layer 1：物理的認知 | Layer 2：性質と解像度 | Layer 3：心象と意味 |
|---|---|---|---|
| 視覚（Visual） | 形状・存在（例：四角い、大きい、そこにある） | 色彩・光影・動き（例：鈍い銀色、明滅する、揺れる） | 印象・比喩（例：威圧的な、希望のような） |
| 聴覚（Auditory） | 音源・種類（例：足音、雨音、話し声） | 音質・距離・反響（例：硬い、くぐもった、遠ざかる） | 感情・情緒（例：寂しげな、神経を逆撫でする） |
| 触覚（Tactile） | 接触・温度（例：触れた、冷たい、熱い） | 質感・圧力（例：ザラザラした、重い、鋭い） | 身体的反応・浸透（例：芯まで冷える、鳥肌が立つ、安堵する） |
| 嗅覚（Olfactory） | 発生源（例：土、珈琲、煙） | 濃度・広がり（例：鼻をつく、微かに漂う、充満する） | 記憶・感情の喚起（例：昔を思い出す、安心する、胸が痛む） |
| 味覚（Gustatory） | 基本味（例：甘い、苦い、しょっぱい） | 複雑さ・食感（例：奥深いコク、舌にまとわりつく） | 精神的充足・不快感（例：心まで満たされる、砂を噛むような） |


# 情景深度テンプレート（プロトタイプ）
| シーンの目的 | 重視するベクトルと深度 | 描写の意図と効果 |
|---|---|---|
| ① 無機質・孤独 | 視覚(L3) × 聴覚(L1) | 視界に入る景色には自分の感情を投影してしまう（L3）のに、耳に入る音はただの物理現象（L1）として冷たく処理される。世界から切り離されたような孤独感や、ちぐはぐな寂しさを際立たせる型ね。 |
| ② 郷愁・回想 | 嗅覚(L3) × 視覚(L1) | 特定の匂い（L3）が強烈に過去の記憶と感情を引き出し、反対に目の前の現実の景色（L1）はただそこにあるだけの形としてしか認識できない状態。意識が過去へ飛んでいる感覚を表現できるわ。 |
| ③ 緊迫・焦燥 | 聴覚(L3) × 触覚(L3) × 視覚(L1) | 耳障りなノイズ（聴覚L3）や、嫌な汗・心拍（触覚L3）といった内側への刺激が極限まで高まり、視界は極端に狭くなって目の前の輪郭（視覚L1）しか見えない。心理的なパニック状態を作る型よ。 |
| ④ 安堵・受容 | 触覚(L3) × 味覚(L3) | 例えば温かいスープを飲んだ時のように、手触りや温度（触覚L3）と、内側から広がる味（味覚L3）に意識を向ける。外の情景をあえて遮断し、内面の充足感を描く時に有効ね。 |

# 使用例
## 窓越しの別れ
【シチュエーション】
カフェの窓際の席。決定的な別れ話の直後、立ち去った相手が雨の降る街へと消えていくのを、一人で窓越しに見送っているシーン。
【フレームワーク指定条件】
 * 深度アライメント：ネガティブ（－） / 喪失感、断絶、虚無感
 * 深度コスト上限：5
 * ベクトルと深度の割り振り：
   * 視覚（Level 1）＝ コスト1：形状・存在のみ（例：遠ざかる背中、雨粒、ガラス）
   * 聴覚（Level 1）＝ コスト1：音源・種類のみ（例：BGM、くぐもった環境音）
   * 触覚（Level 3）＝ コスト3：身体的反応・心象への浸透（例：ガラスの冷たさ、指先の温度と孤独感のリンク）
この指定の意図（解説）
一番感情が動いているはずなのに、ショックで視覚と聴覚の解像度が極端に落ちていて、ただ「そこにあるもの」「鳴っているもの」としてしか認識できていない状態。
その代わり、窓ガラスに触れた指先や、残された飲み物の温度といった「触覚」だけに意識が集中し、そこにすべての喪失感が流れ込んでいく。
情報量をあえて絞り込み、触覚のLevel 3に重みを持たせることで、静かで残酷な別れの余韻を演出できる。

## 例文
彼は何も言わず、テーブルに一枚の1万円札だけを置いて立ち去ってしまった。
遠ざかる背中を目で追ってみても、窓の外はただ無機質に雨が降り続いている。さっきまで心地よく鼓膜を揺らしていたはずのテナーサックスの音色は、今の私にとっては、ただの音階の羅列でしかなかった。
冷たいガラスから手を離し、テーブルに残された紙幣に触れる。そこに残るわずかな熱を両手で包み込み、ゆっくりと額に押し当てた。
ふと、彼に優しく撫でられたような錯覚がして、思わず自嘲の笑みがこぼれる。もう、どこにも彼はいないのに。
